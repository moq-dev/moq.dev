I saw an [Anthropic blog post about formal verification](https://www.anthropic.com/research/formal-verification).
Like most programmers, I don't even test my code, let alone formally verify it.
But I figured I'd play along and waste a few more tokens chasing the dragon.

Because like, if you can **prove the vibe slop is correct**, it's no longer vibe slop right?

<figure>

Green boxes are formally verified, dashed are *mostly* formally verified.

`libcrux` is cool because they try to formally verify everything, but if you saw the last grid, it's super slow.
`rind` will only use a formal proof if the performance was within 10%, which has surprisingly decent coverage.

**aes-gcm** being verified on some architectures is awesome, because it's the goat of crypto.

I'm sure we could get **every algorithm formally proven**.
If only there was somebody in the audience works for a **frontier lab** and wants some easy marketting piece instead of stealing all of the glory from the mathematicians.
