# Vibe Slopped Cryptography
I'm one of the OG "rewrite it in Rust" guys.
**I love Rust**.

Unfortunately, I wrote my last line of Rust 6 months ago.
I still want Claude to write everything in Rust, but it's difficult when **rustc** turns my desktop into lava.

I spent some tokens investigating on how to speed up builds for MoQ.
One finding was that `aws-lc-rs` takes 60s+ to build.
**wtf** why does a single crate take a *full minute* to build?

Despite the suffix, `aws-lc-rs` is actually a `C` library in disguise.
Same with the next best crypto library: `ring`.
**wtf is C doing in my Rust library**.

I did what any sane software engineer does in `current_year`,
I pulled a 9-year old gaming PC out of the closet, installed Claude, and ran `/goal rewrite it in rust` \*.

\* and a lot of assembly

## WOW FAST

This statement alone *should* fill me with mortal dread, but AI is advancing so quickly that it's **no longer absurd**.

^ This is a **big deal** because AES-128-GCM is the most popular TLS cipher suite by far.
Even this relatively tiny reduction in CPU usage has huge impact when multiplied across **every HTTPS request in the world**\*.

Rind started as fork of [Graviola](https://github.com/ctz/graviola) and quickly morphed into a monsterish combination of [ring](https://github.com/briansmith/ring) and [aws-lc-rs](https://github.com/aws/aws-lc-rs) (both fork BoringSSL, a fork of OpenSSL). Bits of [libcrux](https://github.com/celabshq/libcrux) were throw in there for good measure.

The engineers who developed these libraries are smarter than me.
But I have a credit card in `current_year` and don't need to be smart any more.

\* this benchmark is HTTP/3 specific. HTTP/1 and HTTP/2 use different payload sizes.

```toml
# safer/faster API
rind = "0.3"

# if you use ring
ring = { package = "rind-ring", version = "0.17" }

# if you use rustls
rustls = { version = "0.23", default-features = false, features = ["std", "tls12"] }
rind-rustls = "0.23"

# if you use aws-lc-rs
aws-lc-rs = { package = "rind-aws-lc-rs", version = "1" }
```

There's other adapters too if you're lazy.
