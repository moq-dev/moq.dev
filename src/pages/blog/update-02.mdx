## 0.22 for Everything
- First cut is a **shared minor**: `just version 0.22.0` moves every published package to 0.22.0 across Rust, npm, Python, Go, Swift, Kotlin, Dart, C, and C++ (`RELEASE.md`). Patches stay independent per package afterwards.
- Exempt: `kio`, `kio-macros`, `qmux`, `@moq/qmux`.
- Only `hang` (0.21.x) would have hit 0.22 naturally. `moq-net` 0.3 → 0.22 and `@moq/watch` 0.6 → 0.22 are big jumps; explain why (one number to ask "what version are you on?").
- Breaking API cleanup: API audits deleted/privatized unused public surface, banned `doc(hidden)`, `Option` instead of sentinel values. [moq#8461](https://github.com/moq-dev/moq/pull/8461), [moq#8088](https://github.com/moq-dev/moq/pull/8088), [moq#8265](https://github.com/moq-dev/moq/pull/8265), [moq#8392](https://github.com/moq-dev/moq/pull/8392), [moq#8247](https://github.com/moq-dev/moq/pull/8247)
- Every package has a `MIGRATE.md`. Link them.

- moq-transport: dropped drafts 14–17 and 19–21, then brought 20 back. Supported: **18, 20, 22**. [moq#6753](https://github.com/moq-dev/moq/pull/6753), [moq#6754](https://github.com/moq-dev/moq/pull/6754), [moq#7190](https://github.com/moq-dev/moq/pull/7190)

## Our Own QUIC Stack (on rind)
- `moq-quic`: in-tree import of quinn-proto, BBR3 as the default congestion controller. `moq-tokio` and `moq-uring` run on it. [moq#4879](https://github.com/moq-dev/moq/pull/4879), [moq#4921](https://github.com/moq-dev/moq/pull/4921), [moq#5664](https://github.com/moq-dev/moq/pull/5664)
- Native crypto moves to [rind](/blog/rind); aws-lc-rs is gone. [moq#7873](https://github.com/moq-dev/moq/pull/7873), [moq#8250](https://github.com/moq-dev/moq/pull/8250)

## Subscriptions, Reworked
- Subscriptions take `Delay { min, max }`. [moq#7597](https://github.com/moq-dev/moq/pull/7597)
- Fetch is now a range of a subscription. [moq#7545](https://github.com/moq-dev/moq/pull/7545)
- Datagram tracks are their own kind of track. [moq#6949](https://github.com/moq-dev/moq/pull/6949), [moq#7752](https://github.com/moq-dev/moq/pull/7752)
- Group IDs past 2^53 are `bigint` in JS. [moq#7681](https://github.com/moq-dev/moq/pull/7681)
- TODO: a code before/after.

## Auth
- Tokens are per connection; relays enforce bitrate caps. [moq#6834](https://github.com/moq-dev/moq/pull/6834), [moq#7535](https://github.com/moq-dev/moq/pull/7535)
- Clustered relays authenticate each other with mTLS; `moq auth serve` does mesh enrollment. [moq#8301](https://github.com/moq-dev/moq/pull/8301), [moq#7301](https://github.com/moq-dev/moq/pull/7301)
- A credential is a handle in every binding. [moq#8516](https://github.com/moq-dev/moq/pull/8516)
- Roles as patterns, dialed `host` (moq-auth CHANGELOG).

## Relay Performance
- QUIC endpoint sharded per core; moq-transport served from the io_uring workers; QUIC-LB forwarding. [moq#5688](https://github.com/moq-dev/moq/pull/5688), [moq#5821](https://github.com/moq-dev/moq/pull/5821), [moq#7539](https://github.com/moq-dev/moq/pull/7539)
- Two performance audits cut the relay's live read cost. [moq#7874](https://github.com/moq-dev/moq/pull/7874), [moq#6281](https://github.com/moq-dev/moq/pull/6281)

## Congestion Control
- New `moq-congestion` crate; SCReAMv2 and GCC as candidate controllers; bring your own controller. [moq#6602](https://github.com/moq-dev/moq/pull/6602), [moq#7547](https://github.com/moq-dev/moq/pull/7547), [moq#7546](https://github.com/moq-dev/moq/pull/7546)

## Transports
- WebSocket fallback that upgrades to QUIC once UDP works. [moq#4180](https://github.com/moq-dev/moq/pull/4180), [moq#8330](https://github.com/moq-dev/moq/pull/8330)
- MoQ over WebRTC data channels; QUIC and WebRTC media share one UDP port. [moq#5702](https://github.com/moq-dev/moq/pull/5702), [moq#5595](https://github.com/moq-dev/moq/pull/5595)
- HTTP, RTMP, and `tls://` share one TCP port. [moq#7095](https://github.com/moq-dev/moq/pull/7095), [moq#7362](https://github.com/moq-dev/moq/pull/7362)
