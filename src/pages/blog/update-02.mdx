## 0.22 for Everything
- First cut is a **shared minor**: `just version 0.22.0` moves every published package to 0.22.0 across Rust, npm, Python, Go, Swift, Kotlin, C, and C++ (`RELEASE.md`). Patches stay independent per package afterwards.

## Groups Are Timestamps
- The big one. Groups are addressed by their start timestamp, not a sequence number, in moq-net (Rust and JS), the FFI, and every binding. Readers seek or join from a time; no producer remembers group numbers. Older wires carry the key verbatim as the group ID, so old peers keep working. [moq#8638](https://github.com/moq-dev/moq/pull/8638), [moq#8908](https://github.com/moq-dev/moq/pull/8908), [moq#8915](https://github.com/moq-dev/moq/pull/8915), [moq#9002](https://github.com/moq-dev/moq/pull/9002)
- Every write takes a required `Timestamp { value, scale }`; JS group starts are `bigint`.
- Catalog updates take effect at their timestamp. [moq#8907](https://github.com/moq-dev/moq/pull/8907), [moq#9281](https://github.com/moq-dev/moq/pull/9281)

## Subscriptions, Reworked
- A subscription is a set of ranges. A live join is a range with a `Live { min, max }` start: `min` reaches back from the live edge, `max` is that range's staleness budget. History ranges (time, position, oldest) deliver in full. So one DVR viewer no longer stretches every live viewer's budget on a relay. Replaces `Delay { min, max }` from earlier on `main`. [moq#9316](https://github.com/moq-dev/moq/pull/9316), [moq#9409](https://github.com/moq-dev/moq/pull/9409), [moq#9490](https://github.com/moq-dev/moq/pull/9490)
- Fetch is a range of a subscription; a lite-07 range may start partway through a group, so a route switch resends nothing. [moq#7545](https://github.com/moq-dev/moq/pull/7545), [moq#9155](https://github.com/moq-dev/moq/pull/9155)
- Each range gets its own SUBSCRIBE_START, so a live join through a relay waits on its upstream. [moq#9444](https://github.com/moq-dev/moq/pull/9444); every track (pending, [moq#9491](https://github.com/moq-dev/moq/pull/9491))
- Datagram tracks are their own kind of track. [moq#6949](https://github.com/moq-dev/moq/pull/6949), [moq#7752](https://github.com/moq-dev/moq/pull/7752)
- Tracks refresh by interval or on request. [moq#9054](https://github.com/moq-dev/moq/pull/9054)

## Flow Control
- Receive credit is leased: a relay pauses a stream while its writer runs ahead of the fastest reader, and any number of streams can pause. Smaller default windows. [moq#7624](https://github.com/moq-dev/moq/pull/7624), [moq#9210](https://github.com/moq-dev/moq/pull/9210)
- Session stats count send-credit stalls, time sends held by congestion control, and count lost bytes, so the failure mode is visible. [moq#9328](https://github.com/moq-dev/moq/pull/9328), [moq#9446](https://github.com/moq-dev/moq/pull/9446), [moq#9398](https://github.com/moq-dev/moq/pull/9398)

## Auth
- Tokens are per connection, written as documented with a typed `jti`; relays enforce bitrate caps and refuse grants they don't fully understand. Grants are path prefixes again. [moq#6834](https://github.com/moq-dev/moq/pull/6834), [moq#7535](https://github.com/moq-dev/moq/pull/7535), [moq#9001](https://github.com/moq-dev/moq/pull/9001), [moq#8933](https://github.com/moq-dev/moq/pull/8933), [moq#9251](https://github.com/moq-dev/moq/pull/9251)
- Clustered relays authenticate each other with mTLS, and a cluster peer's token rotates on its live session. [moq#8301](https://github.com/moq-dev/moq/pull/8301), [moq#9403](https://github.com/moq-dev/moq/pull/9403), [moq#9380](https://github.com/moq-dev/moq/pull/9380)
- A credential is a handle in every binding; a reconnecting client carries it in the URL's `auth` parameter. [moq#8516](https://github.com/moq-dev/moq/pull/8516), [moq#9215](https://github.com/moq-dev/moq/pull/9215)
