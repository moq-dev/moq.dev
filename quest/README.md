# moq.dev questline

## Goal

Keep the living work on moq.dev, moq.pub, and moq.watch organized as visible,
versioned quests, grouped into milestones ordered by priority.

## Plan

This tree tracks the sites: the blog, the demos, moq.pub, and moq.watch.
Protocol, player, and publisher fixes are quests in
[moq-dev/moq](https://github.com/moq-dev/moq/tree/main/quest) and arrive here
only as a package bump. A draft blog post stays a draft PR, which already holds
its scope, until it is scheduled.
